# Formulário de Login

Teste do Formulário de Login desenvolvido com react-hook-form e zod por @lucivandosousa.

## Passos para executar o projeto

1. Clone os repositórios:

```bash
git clone https://github.com/lucivandosousa/hook-form-zod

git clone https://github.com/edinetesousa/test-hook-form-zod
```

2. Navegue até o diretório do projeto React:

```bash
cd hook-form-zod
```

3. Instale as dependências do projeto React:

> **Aviso:** A versão do Node.js necessária para rodar este projeto é **v20.11.0** ou superior.

```bash
npm install
```

4. Rodar o projeto React:

```bash
npm run dev
```
Abra o navegador e acesse http://localhost:5173 para ver o aplicativo em execução.

## Testes

5. Acesse a pasta do Teste:
```bash
cd test-hook-form-zod
```
6. Instale as dependências do Teste:
```bash
npm cypress install
```

```bash
npm install @faker-js/faker --save-dev
```

```bash
npm install --save-dev @shelex/cypress-allure-plugin allure-commandline
```

6. Execute os testes:
```bash
npm run test
```
